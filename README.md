## ⚡ Build & Run Commands

### 1. Production Build
Executes the zero-dependency build pipeline, bundles JavaScript, minifies CSS/HTML, and generates the optimized `dist/` directory:
```bash
npm run build
```
**Build Performance:**
- **Execution Speed**: ~30 ms
- `dist/index.html`: 36.4 KB (8.5 KB gzipped)
- `dist/css/style.min.css`: 31.6 KB (6.0 KB gzipped)
- `dist/js/app.bundle.js`: 43.3 KB (13.1 KB gzipped)

### 2. Preview Production Build
Starts the local preview server pointing directly to the compiled `dist/` folder:
```bash
npm run preview
# Serves at: http://localhost:4173
```

### 3. Development Server
Starts the local development server with unminified hot assets:
```bash
npm start
# or npm run dev
# Serves at: http://localhost:3000
```

### 4. Direct Browser Opening
No server required! Simply double-click either:
- Development: `c:\Users\ASUS\Desktop\lumina-events\index.html`
- Production: `c:\Users\ASUS\Desktop\lumina-events\dist\index.html`

## 🌟 Key Platform Features

1. **Interactive Event Investment & Scope Estimator**:
   - Dynamic real-time calculation engine across event typologies (*Luxury Wedding*, *Corporate Gala*, *Milestone Soirée*, *Brand Showcase*).
   - Interactive attendance slider (30 to 600+ guests).
   - Production tier multipliers (*Full-Service Bespoke*, *Design & Curation*, *Month-Of Direction*).
   - Toggleable add-on experiences (Mixology Atelier, Scenography, Headliners, 4K Cinema, Chauffeur Concierge).
   - Dynamic allocation model breakdown (Management 20%, Venue/Catering 42%, Scenography 23%, Media 15%).
   - Seamless scope prefill into the Consultation Scheduler.

2. **Curated Portfolio & Interactive Modal Lightbox**:
   - Category filtering (*All*, *Weddings*, *Corporate*, *Private Celebrations*).
   - Lightbox modal featuring client narratives, spatial challenges solved, planning timeline, vendor count, sustainability ratings, and harmonic color swatches with hex codes.

3. **The Exclusive Events 4-Phase Production Method**:
   - Interactive workflow switcher across Phase 01 (*Vision & Spatial Architecture*), Phase 02 (*Curation & Sensory Design*), Phase 03 (*Logistical Blueprint*), and Phase 04 (*White-Glove Orchestration*).

4. **Aesthetic Moodboard Visualizer**:
   - Live visual explorer for *Gilded Obsidian Noir*, *Tuscan Sun & Olive*, *Luminescent Cloud & Pearl*, and *Verdant Glasshouse Botanica*.

5. **Signature Services Catalog**:
   - Comprehensive deliverables checklists, ideal lead times, and transparent pricing indicators.

6. **3-Step Consultation Scheduler Wizard**:
   - Progressive validation, vibe and budget selection, consultation format preferences (Virtual, Manhattan, London, Paris, Phone), and instant confirmation cards with unique booking reference codes (e.g. `EXCL-2026-XXXX`).

7. **Client Praise, Press Accolades & Expandable FAQ**:
   - Verified 5-star reviews, publication badges (*Vogue*, *Harper's Bazaar*, *Forbes Life*, *Architectural Digest*), and accordion FAQs.
